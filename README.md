# FAR AWAY

This project is recreated using NextJS 15 from Jonas Scmedttmann React Course. I am trying to switch from React mental model into NextJS mental model by building this project.

## Running on local

Install the packages by using

```bash
npm install
```

Then run development server

```bash
npm run dev
```

## Tech stack

- NextJS 15
- TailwindCSS v3.4
- Prisma
- SQLite
